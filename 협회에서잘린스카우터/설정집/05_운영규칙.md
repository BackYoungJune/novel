# 작품 운영 규칙

## 에피소드 반복 구조 (한 사이클 3~5화)
숨은 S급 발견 → 영입 설득 → 개화 조건 해결 → 재등급 심사로 사이다 → 주인공 파편 획득 → 협회·대형 길드의 반응

## 전투 단계 (확정)
| 부 | 주인공 상태 |
|---|---|
| 1부 | 파편 1~2개로 약함. **비전투**. 감정과 협상으로 이긴다 |
| 2부 | 자기 몸을 지킬 수준. 결정적인 순간에만 개입 |
| 3부 | 본격 전투. 제자들과 합동 전투 |
| 4부 | 모든 계열을 조합하는 유일한 존재 |

## 연재 규칙 (시장조사 기준)
- 화당 약 5,500~6,000자, 하루 1화(주 7회), 고정 시각 연재. 12시 또는 21시를 시험한다.
- 연재 시작 전 최소 15화 비축.
- 유지율 목표 (1화 조회 대비): 2화 85% 이상, 5화 75% 이상, 10화 60% 이상.
- 소개글은 1~2문장(40자 안팎), 태그는 5~6개.

## 톤
- 주 독자: 남성 약 87%, 40~50대가 65~75%.
- 직장 경험, 가장의 책임감, 현실적인 돈 감각이 공감 포인트. 사이다에 힐링을 섞는다.

## 금지
- 측정기가 잠재력을 재는 전개 (세계관 핵심 규칙 위반)
- 파편이 원본 제자를 넘어서는 전개
- 1부에서 주인공이 직접 싸우는 전개
