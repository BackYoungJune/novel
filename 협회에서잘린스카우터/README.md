# 협회에서 잘린 스카우터가 F급만 데려갔더니 전부 S급

문피아 일반연재 목표 웹소설. 현대판타지 + 퓨전 (헌터 × 해고 × 재능 감별 × 재벌).

## 한 줄 요약
AI 측정기 도입으로 협회에서 잘린 45세 스카우터가, 남들이 버린 F급 속 숨은 S급을 알아보고 키우며, 키울수록 자신도 강해진다.

## 등록 정보 (확정) — [10_등록정보](설정집/10_등록정보.md)
**소개글**
```
협회에서 잘렸다. 사람을 기계로 재기 시작한 날.
그 기계가 못 재는 걸 나는 본다.
```
**태그** 현대판타지 · 헌터 · 사이다 · 각성 · 성장 · 회사원
