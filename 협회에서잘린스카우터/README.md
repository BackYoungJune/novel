# 협회에서 잘린 헌터 스카우터가 S급만 골라 키움 (가제)

문피아 일반연재 목표 웹소설. 현대판타지 + 퓨전 (헌터 × 해고 × 재능 감별 × 재벌).

## 한 줄 요약
AI 측정기 도입으로 협회에서 잘린 45세 스카우터가, 남들이 버린 F급 속 숨은 S급을 알아보고 키우며, 키울수록 자신도 강해진다.

## 제목 후보 ([10_등록정보](설정집/10_등록정보.md) 참조)
- 협회에서 잘린 헌터 스카우터가 S급만 골라 키움 (원안)
- **협회에서 잘린 스카우터가 F급만 데려갔더니 전부 S급 (권장, 실측 패턴 일치)**
- 잘린 협회 스카우터 눈엔 F급이 S급으로 보인다
