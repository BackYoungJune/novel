# GPT 전달: 017~066화 진행 개작 요청 (초안, 2026-11-01)

작가 지시(2026-11-01): "나머지 회차도 개작 요청 넣어줘". [009~016 요청](GPT_009-016화_진행개작요청_2026-11-01.md)의 다음 범위다. Claude(Opus 5.5)가 [1~66화 진행 점검](1-66화_진행점검_2026-11-01.md)과 개작된 001~008의 바뀐 사실을 017~066 원고와 대조해 정리했다. **원고는 고치지 않았다.** 개작은 GPT(Codex)가 맡는다.

## 1. 순서와 일정

- **009~016을 먼저 끝낸다.** 이 문서의 작업은 그다음이다.
- 매일 연재가 이어지면 017은 2026-11-10, 이후 하루 한 화씩이다(n화 공개일 = 11-10 + (n−17)일, 066은 12-29). 아직 어느 플랫폼에도 예약되지 않았다.
- **공개일보다 최소 3화 앞서 개작을 유지한다.** 서버는 [진행 점검](1-66화_진행점검_2026-11-01.md)에 `개작 완료`가 붙고 커밋이 `origin/main`에 있는 회차만 문피아에 예약한다. 개작이 밀리면 연재가 멈춘다.
- 네이버 예약은 작가가 한다. 개작이 끝날 때마다 작가에게 알린다.

## 2. 작가 결정이 먼저 필요한 것 — 해당 묶음에 닿기 전에 묻는다

GPT는 아래를 임의로 정하지 않는다. 해당 회차를 시작하기 **최소 이틀 전**에 작가에게 선택지를 올린다.

| 묶음 | 통합 제안 | 늦어도 물을 때 |
|---|---|---|
| 태현 반환금 | 023·025·026 → 2화 | 022 작업 시작 전 |
| 폐마석 실험 | 028·029 → 1화 | 027 작업 시작 전 |
| 길드 공급 거래 | 034·035·037 → 2화 (032·036 수리 장면 정리) | 031 작업 시작 전 |
| 서아 재회 | 038·039 → 1화 | 037 작업 시작 전 |
| **2부 전체** | **051~066 구성안 재작성** + 병원의 밤(051~053 → 2화), 고백(054·055 → 1화), 공개 문서(056~058 → 2화), 길드 4시간(061·062·064·066 → 2~3화) | 045 작업 시작 전 |

- **통합하면 회차 번호가 바뀐다.** 이미 공개·예약된 016까지는 영향이 없지만, 017 이후의 제목·번호·분량 계획이 달라진다. 작가가 고른 뒤 회차목록·구성안·대장을 함께 고친다.
- **통합하지 않으면** 각 화 안에서 압축만 한다. 상 등급 회차는 지운 문답 자리를 기존 구성안의 사건 안에서 채운다. 새 사건이나 새 설정이 필요하면 작가에게 제안으로 올리고 확정하지 않는다.
- 2부(051~)는 진행 점검이 **구성안을 먼저 다시 쓰라고** 권했다. GPT는 2부 개작 전에 `구성/51-66화_진행재설계_(초안).md` 같은 재설계안을 만들어 작가 승인을 받는다. 승인 전에는 051 이후 본문을 개작하지 않는다.

## 3. 읽을 것과 바꾸지 않는 것

- [009~016 요청서](GPT_009-016화_진행개작요청_2026-11-01.md) 2·3·7절의 준비 사항, 고정 사항, 완료 조건을 그대로 따른다.
- 구성안: [16-20화](../구성/16-20화.md), [26-33화](../구성/26-33화.md), [51-55화](../구성/51-55화.md) 등 해당 구간 문서와 [26-50화 재미 검증](26-50화_구성_재미검증_2026-10-18.md).
- 확정·위임 결정을 지킨다(작가결정 로그). 특히 14→15→17→18→19화의 점진적 신뢰 형성(2026-10-13 위임), 055의 공개 범위는 치유 계열 인지 사실로 제한, 태현이 검증·계약 문구 정리 뒤 길드에 직접 밝히는 순서(2026-10-23), 진호→채원 호칭은 1부 '학생', 2부 '채원 씨'.
- 1부(~050) 진호 비전투. 하루 감정 5회(1부). 22명 명단의 분류는 [26-33화 구성](../구성/26-33화.md) 부록 B와 1화 개작본 내역(셋 활동·한 명 B급, 넷 등록 포기, 여섯 연락 끊김, 하나 사망, 여덟은 진호도 모름)을 따른다. Claude 대조 결과 017~066 원고의 22명 언급은 이 내역과 충돌하지 않는다.
- 분량: 017~066은 기본 5,500~6,000자다. 압축 예외(001~009)는 적용되지 않는다.

## 4. 공통 지시 — 구간별

회차별 진단(바뀐 것·보상·늘어지는 곳·줄 번호·수정 방향)은 [진행 점검](1-66화_진행점검_2026-11-01.md)의 해당 절을 따른다. 아래는 여러 화에 걸친 지시다.

### 017~021 (1부 중반: 신뢰와 첫 재등급)
- 019·020은 기준 예시(하)다. 문장만 정리한다.
- 017(중)·021(중): 021의 22명 현황 첫 보고는 **한 번 제대로 읽는 장면**으로 둔다. 이후 029·032·033에서는 새로 확인된 사실 한 줄씩만 쓴다(점검 반복 문제 3).

### 022~026 (태현 반환금)
- 한 사건을 다섯 화에 걸쳐 문서로 협의한다(반복 문제 2). 023·025·026이 상이다.
- 통합하지 않으면: 각 화에서 조항 순회를 두 고비로 줄이고, 태현이 실제로 잃을 수 있는 것(7년, 900만 원, 다음 계약)을 장면 안의 선택으로 보여 준다. 025의 7년 계약은 서명하지 않는다는 사실을 유지한다.

### 027~033 (폐마석·22명 후속)
- 027·030·031은 하. 028·029의 시도 → 실패 → 기록 반복을 한 번의 실험과 한 번의 반전으로 줄인다(반복 문제 4).
- 029·032·033의 22명 소식은 021을 다시 설명하지 않는다.

### 034~039 (길드 공급 거래·서아 재회)
- 034·035·037(상)은 조항 순회형 협상이다(반복 문제 1). 상철의 몫과 회사 몫, 길드의 요구 중 **누가 무엇을 양보했는지**가 장면 끝에 보이게 한다. [26-33화 구성](../구성/26-33화.md) 부록 A(제작 순이익 배분, 60/40 유지)를 지킨다.
- 038·039 서아 재회는 1화 계단 장면(서아는 진호를 모른다, 진호는 이름만 봤다)과 이어진다. 1화 개작본의 계단 묘사(명함첩, "저기—" 한마디)와 어긋나지 않는지 대조한다.

### 040~050 (1부 마무리)
- 040·043·046·047·049는 기준 예시(하)다. 041·044·048·050도 하. 042·045만 중이다.
- 047·042는 'A가 아니라 B' 계열 정리 문장이 7~11회로 많다. 진호의 판단·계산으로 바꾼다(반복 문제 5).
- 043~045의 시험판 반복은 한 번의 시험과 결과로 줄인다.

### 051~066 (2부) — 구성안 재작성 승인 뒤
- 052·056·057·059·061·062·066이 상이다. 병원의 밤, 공개 문서, 4시간 협의가 각각 여러 화에 걸쳐 있다.
- 066 초고의 교차 검토 지적([66화 교차검토](66화_교차검토_2026-11-01.md))을 함께 반영한다. 066은 65화 끝의 발견을 다시 하고 시작과 끝이 같다. 월요일 길드 면담을 이 화에서 벌이라는 권고가 있다.
- **064/065 가방 불일치:** 064에서 진호가 "가방은 제가 들죠"라고 하는데 065에서는 상철이 가방을 들고 진호는 입구 쪽에 선다. 진호의 가방이 어디서 넘어갔는지 한 줄로 잇거나, 064 대사를 065에 맞춘다. 064의 가방 대사(12_인물말투 예시 1)는 살린다.

## 5. 개작 중 확인할 연속성

- 009~016을 먼저 개작하므로, **017 이후를 고칠 때는 개작된 009~016을 다시 읽고** 017 이후가 지워진 장면·대사를 참조하지 않는지 대조한다. 예: 016의 유진 문답을 줄이면 017 이후의 "그때 유진이 한 말" 같은 참조가 끊길 수 있다.
- 001 개작본의 바뀐 사실(진호가 권고사직서에 직접 서명, 유진에게 22명 파일을 직접 넘김, 오후 4시 계정 종료)을 017~066이 다르게 말하지 않는지 본다. Claude가 사직서·명함첩·파일 인계·22명 내역을 검색한 결과 017~066에서 충돌은 찾지 못했다.
- 대장과 원고가 다르면 원고를 확인하고 대장을 고친다.

## 6. 완료 조건

[009~016 요청서](GPT_009-016화_진행개작요청_2026-11-01.md) 7절과 같다. 회차마다 게시본 재생성, 분량·"나는" 측정, 자체 점검, 가능하면 교차 검토, 진행 점검의 `개작 완료` 표시, 연속성 대장 새 절, 커밋·푸시, 작가에게 네이버 교체·예약 알림 순서로 한다. 통합을 작가가 고른 묶음은 회차목록·구성안·연재운영 대장의 회차 번호도 함께 고친다.
