## Git 및 재개 순서

작가는 이번 퇴고·규칙·기록의 커밋과 원격 main 푸시를 명시적으로 요청했다. 이 문서에 커밋 해시를 고정하지 않는다. 반영 여부와 이후 타 작업자 변경은 재개 시 Git으로 확인한다.

1. `git status --short`와 `git log -3 --oneline`으로 최신 변경을 확인한다. 원격 확인 요청이 있으면 fetch 후 분기 차이를 확인하고, 로컬 작업을 덮어쓰지 않는다.
2. [작품 README](../README.md), [작가 결정 로그](작가결정_로그.md), [연속성 대장](연속성_대장.md), [교차 검토 기록](문장연결_퇴고_2026-10-02.md)을 읽는다.
3. `./task-start` 지침에 따라 새 사용자 요청을 분류한다. 새 작업 범위가 없으면 원고를 임의로 이어 쓰지 않는다.
4. 본문 작업은 설정집 01~11·해당 구성안·앞뒤 원고를 대조한다. 분량은 실제 수정 대상 번호로 `./task-start.ps1 -Mode review -Chapters ...`를 실행한다.

재개 메시지 예시: `./task-start. 기록/작업인계_2026-10-02.md부터 읽고 현재 상태를 확인해줘.`
