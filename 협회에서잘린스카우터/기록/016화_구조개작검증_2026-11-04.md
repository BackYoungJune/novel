# 016화 새 구조 기준 재개작·자체 검증 (초안, 2026-11-04)

## 구조와 변경 이유

작가의 2026-11-04 전체 구조 재개작 지시에 따라 [016 원고](../원고/016.md)를 [016~018 묶음 지도](../구성/016-018화_구조개작지도_2026-11-04.md), 015·017과 대조했다. 유진의 길드 측정실 제안은 채원의 현재 F가 지원 우선순위에 쓰이는 외부 압박이고, 채원은 자기 공략의 선택·기록을 한 수치로 지우지 않겠다고 거절한다. 진호는 7월 공식 심사를 꺼내지만 채원에게 먼저 묻지 않아 제지당한다. 기존 본문의 긴 판단 설명을 달력과 접힌 도면을 보는 행동으로 줄여 진호의 앞선 말이 바로 채원에게 걸리도록 했다. 상철의 숨긴 손 상처는 철판 받침 수정으로, 게시판의 '다시F' 반응은 채원의 직접 기록으로 이어지는 기능을 유지했다.

## 목적 충돌·직접 보상

| 장면 | 원하는 것 / 막는 것 | 끝에 달라진 것 |
|---|---|---|
| 길드 측정 제안 | 유진은 공식 F인 채원의 두 번 공략을 검증하고 지원 여부를 판단하려 한다 / 진호는 훈련 동작과 안전을 기록해야 하고 채원은 길드 기록 활용을 원치 않는다 | 채원이 즉시·다음 날 길드 측정을 거절한다. 진호가 7월 심사를 제안하지만 채원이 자기 동의가 먼저라고 제지한다 |
| 손 상처·공개 반응 | 팀은 015에서 다친 상철의 손을 기록하고 다시 베이지 않게 해야 한다 / 상철은 저림만 말하고 베인 상처는 빼먹었다 | 진호가 부상 부위와 밀린 철판을 적고 손으로 받치지 않을 받침을 주문한다. 게시판의 '다시F'는 등급은 그대로여도 철수 선택이 달라질 수 있음을 보여 채원이 훈련 노트에 자기 느낌을 적는다 |
| 공식 심사 접수 | 채원은 다시 F가 나와도 공략 기록이 사라지지 않는지 확인하려 한다 / 유진은 3주 뒤 결과를 요구하고 진호는 결과를 장담할 수 없다 | 채원이 7월 심사 신청 버튼을 직접 누른다. 유진에게 접수 번호는 주지 않고 날짜만 알려 준다. 마지막에 유진이 '심사장에서 뵙죠'라고 못을 박는다 |

## 연속성·설정·검증

- 015의 두 번째 공략에서 돌아온 같은 날 사무실 대화다. 채원 공식 등급은 F이고 개화 전이다. 유진은 잠재 S·진호 능력을 모른다. 길드 측정실 제안은 거절되고 실제 측정은 없다. 7월 재등급 심사는 약 3주 뒤이며 채원이 자발적으로 신청한다. 신청 접수 번호가 생기지만 세부 시간은 서류 확인 뒤 안내될 예정이다. 유진은 접수 번호를 받지 않고 날짜만 받는다.
- 상철 손등은 015 철판을 받칠 때 베였고 저림과 별개로 016에서 밴드가 드러난다. 진호가 처음 밀린 철판을 표시하고 다음에는 손으로 받쳐야 하는 판을 가져가지 않겠다고 적는다. 고임쇠는 만들 예정이며 아직 시험·실전 사용 전이다. 채원은 상철 손 상처를 보고 본인의 빠른 처치만으로 위험을 없앨 수 없다는 답을 듣는다.
- 게시판 `다시F`는 세 번째 F 등급에도 이전보다 일찍 철수한 선택을 자기 경험으로 말한다. 채원은 공식 등급 상승이나 감정 결과와 구별해 손목 떨림 감소·자기 체감과 검을 놓친 횟수를 기록하려 한다. 고정 닉의 실제 인물 정체나 등급 변화를 임의 확정하지 않는다.
- `./task-start.ps1 -Mode review -Chapters 16 -AsJson` 결과 원고 본문 5,533자, `나는` 후보 4회로 기본 분량·대명사 한도를 통과했다. 전체 변환 게시본은 5,537자로 회차목록 016행과 일치한다. 015~017 연결·정보 범위·말투·비전투·측정 규칙을 자체 독해했고 독립 교차 검토는 없다.
- 로컬 원고·게시본만 갱신했다. 플랫폼 공개·예약 016화는 교체하지 않았다. **교차 검토 없음 (자체 검증만).**
