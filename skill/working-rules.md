# 스킬 공통 작업 지침 (확정)

2026-10-01 사용자 요청으로 정리. 기존 [AGENTS.md](../AGENTS.md)와 작품 설정집을 적용하는 절차이며 작품 규칙을 대체하지 않는다.

## 시작

- [인덱스](INDEX.md)에서 요청에 필요한 지침을 찾고 실제 파일을 읽는다. 경로와 최신 상태는 파일 목록·git diff로 확인한다.
- 대상 작품·회차, 집필인지 점검인지, 관련 규칙을 짧게 정리한다. 이미 명확한 요청은 재질문하지 않는다.
- 작가는 본문을 직접 수정하지 않고 감독(기획·지시·승인)만 맡는다. 작가 결정 로그와 충돌하지 않게 쓴다. 작가나 타인이 고친 문장이 있으면 우선 보존한다. 확정 설정과 초안·추측을 구분한다.

## 수행과 검증

- 집필은 [novel-write](novel-write/SKILL.md), 검증은 [novel-review](novel-review/SKILL.md)를 따른다.
- ‘점검만’ 요청은 읽기와 보고로 끝낸다. 집필·수정 요청에는 해당 범위의 자체 검증과 오류 수정이 포함된다.
- 숫자 검사와 실제 독해를 구분한다. 분량 검사 통과만으로 설정·문장·흡입력까지 통과했다고 말하지 않는다.
- 분량은 기존 집필 규칙의 계산법과 `task-start`로 재측정한다. 대사 비중은 행 비중과 혼용하지 않고, 종결 어미 비율·장면 구분 개수·인물 등장 횟수만으로 수정하지 않는다. 자세한 기준은 작품의 07_집필규칙·09_문장·03_인물을 읽는다.
- 규칙 충돌은 근거 위치를 확인하고 알린다. 작가가 맡기지 않은 새 기획 결정을 임의 확정하지 않는다.

## 마무리

- diff로 의도한 파일만 바뀌었는지 확인하고 변경된 회차의 분량·연결을 재검증한다.
- 실제 완료한 범위만 작품 README에 반영한다. 해결한 문제와 남은 문제, 검증하지 못한 범위를 구분해 보고한다.
- 반복되는 문제가 확인되면 관련 규칙 원본에 반영할 내용을 제안한다. 승인된 변경은 원본에 근거·절대 날짜를 남기고 인덱스도 맞춘다.
- 커밋하는 경우 기존 커밋 규칙에 따라 `AI 활용 범위:`, 정형 줄(`AI-범위:`, `작가-관여:`), `Co-Authored-By`를 정확하게 남긴다. 스킬 사용 자체가 커밋·푸시·게시의 새 권한을 부여하지 않는다.
