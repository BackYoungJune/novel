# 소설 작업 스킬·규칙 인덱스 (확정)

2026-10-01 작가가 제공한 `.claude`의 인덱스·작업 시작·검증·마무리 구조를 참고해 정리했다. 게임 개발 규칙과 승인 절차는 가져오지 않았다.

## 읽는 순서

1. [공통 작업 지침](working-rules.md)과 [AGENTS.md](../AGENTS.md)를 확인한다.
2. 아래 표에서 요청에 맞는 스킬과 기존 규칙 문서를 찾는다.
3. 원고 작업은 기존 규칙대로 설정집 01~11과 구성/을 먼저 읽는다. 이미 읽은 문서는 변경분만 재확인한다. 추가 자료는 실제 관련이 있을 때 읽는다.
4. 지침의 원본은 기존 설정집이다. 이 인덱스와 스킬에 설정을 다시 복사하지 않는다.

## 관리

- 작업 절차는 `skill/`에서 수정한다. `.agents/skills/`는 Codex용 호출 연결이며 절차 사본을 두지 않는다.
- AGENTS.md와 CLAUDE.md는 같은 스킬을 참조한다. 새 문서가 생기거나 경로가 바뀌면 이 인덱스와 연결도 갱신한다.
- 설정 변경은 근거와 작가 승인 여부를 원본 문서에 기록한다. 검증에서 발견한 추측을 확정 설정으로 올리지 않는다.
