# 원고 집필과 수정 (확정)

2026-09-30 사용자 요청으로 도입. 규칙의 원본은 저장소 AGENTS.md와 작품 설정집이다. 수치·설정·표기 형식을 이 스킬에서 별도로 확정하지 않는다.

## 준비
- [인덱스](../INDEX.md)와 [공통 작업 지침](../working-rules.md)에서 기존 규칙의 원본 경로를 확인한다.
- ../task-start/SKILL.md의 준비가 안 됐으면 1~4단계만 수행한다. 스킬 간 재귀 호출을 피한다.
- 작품 설정집/07_집필규칙.md, 09_문장.md와 해당 구성안을 적용한다. 작가 결정 로그와 충돌하지 않게 쓴다. 작가가 직접 고친 문장이 있으면 우선 보존한다.
- 집필 전 이번 화의 당면 목표, 방해, 시도와 대가, 달라지는 상황, 마지막 미해결 질문을 짧게 정리한다. 본문에 작업용 설명을 넣지 않는다.
- 2026-11-04 작가 확정 규칙: 묶음의 외부 필요·실패 비용과 이번 화에 독자가 현장에서 볼 핵심 사건·보상을 먼저 정한다. 외부 시점·뉴스가 있다면 본편에 닿는 변화를 적는다. 내용이 비면 대사·분량을 채우기 전에 구성을 다시 본다([07_집필규칙](../../협회에서잘린스카우터/설정집/07_집필규칙.md)).
- 구성안의 초안 표시는 유지한다. 집필 요청이 새로운 핵심 설정을 임의 확정하는 허가는 아니다.
- 원고 `원고/NNN.md`의 첫 줄은 `# N화 — 제목`으로 쓰고 `(초안)`·`(확정)` 상태 표식을 붙이지 않는다(2026-11-04 작가 지시). 원고의 승인 상태는 제목 표식으로 판단하지 않는다.

## 집필
- 설명보다 인물의 행동·선택·상대 반응으로 장면을 진행한다. 도입에서 당장 부딪힌 사건을 보여주고 전 화의 약속을 이어받는다.
- 서진호가 아직 확인하지 못한 능력 규칙을 작가 지식으로 단정하지 않는다. 실험·추측·확인된 사실을 구분한다.
- 대사는 인물의 나이·직업·관계·목적에 맞춘다. 정중한 인물을 억지 반말로 바꾸거나 어미만 바꾸지 않는다.
- 인물이 모두 상대 우려를 정확히 정리하고 합리적으로 양보하는 문답을 경계한다. 목적 충돌, 회피, 현장 행동과 그 비용을 원고에 있는 인과로 쓴다. 어색함을 만들기 위한 억지 오해·고함을 넣지 않는다.
- 같은 길이의 “~했다. ~였다.”가 이어지면 원인과 행동을 묶고 대사·반응을 엮는다. 비율 맞추기, 무의미한 명사 단독 줄, “~고.”로 끊는 미완결 문장을 피한다.
- 숫자는 무엇의 수치인지 분명하게 쓴다. “열세 퍼센트, 열다섯 달치”처럼 서로 다른 기준을 맥락 없이 나열하지 않는다.
- 감정 표시는 07의 확정 형식과 해당 시점의 공개 단계만 사용한다. 시스템 창·스킬명·미공개 정보로 확장하지 않는다.
- 본문 공백 포함 5,500~6,000자에 맞춘다. 부족하면 시도·실패·협상·상대 반응을 보강한다. 같은 설명이나 감상을 반복해 채우지 않는다.
- 원고/NNN.md에 저장한다. 제목과 표시는 기존 파일 관례를 따른다.

## 완료 전
1. ../novel-review/SKILL.md를 읽고 방금 쓴 원고를 검증한다. 집필 요청에는 자신의 초고 오류를 고치는 과정이 포함된다.
2. 허용 범위의 문제를 고친 뒤 분량과 수정에 영향받는 연결을 다시 확인한다. 설정 변경이 필요한 문제는 숨기지 말고 남긴다.
3. 연속성 대장(`기록/연속성_대장.md`)을 갱신한다. 원고에서 새로 생긴 고유명사·수치·규칙은 설정집 반영안으로 정리해 보고하고, 작가 승인 전에는 설정집에 확정으로 올리지 않는다.
4. 작품 README 진행 상태를 실제 파일과 맞춘다. 본문을 장황하게 답변에 복사하지 말고 파일·분량·핵심 변경·남은 문제를 보고한다.
5. 커밋할 때 AGENTS의 AI 이력 규칙(`AI 활용 범위:`, `AI-범위:`, `작가-관여:`)을 따른다. 작가가 직접 수정한 부분이 있으면 AI 작업과 한 커밋으로 합치지 않는다.
