# 소설 작업 시작 (확정)

2026-09-30 사용자 요청으로 도입. 경로는 저장소 루트 기준이다.

1. AGENTS.md, 작품 README, git status와 관련 diff를 확인한다. 타인이 수정한 최신 파일을 다시 읽으며 이전 대화 속 원고로 덮어쓰지 않는다.
2. 대상 작품·회차와 요청을 정한다. 대화에서 명확하면 다시 묻지 않는다. 작업 내용 없이 시작만 요청했으면 현황과 다음 작업 후보를 보여주고 임의 집필하지 않는다.
3. 터미널의 ./task-start.ps1은 파일 목록·분량을 출력하는 읽기 전용 도구다. 실행만으로 규칙을 읽었거나 AI 집필이 시작됐다고 간주하지 않는다.
4. 원고 작업 전 작품의 설정집 01~11, 구성/을 읽는다. 같은 작업에서 이미 읽은 파일은 변경분만 확인해도 된다. 대상 원고와 앞뒤 회차를 읽고 날짜·장소·인물별 지식·감정 횟수·부상·돈·계약·복선을 대조한다. 없는 후속 원고는 구성안으로 확인한다.
5. 집필·이어쓰기·퇴고·수정 요청이면 ../novel-write/SKILL.md를 읽고 진행한다. 점검·검증·리뷰 요청이면 ../novel-review/SKILL.md를 읽는다. 명시적인 점검만 요청은 수정하지 않는다. 검증 완료 후 이 스킬을 다시 호출하지 않는다.
6. 설정 충돌과 작가 결정이 필요한 사안만 따로 알린다. 기존 설정 안의 문장 개선에는 재승인을 요구하지 않는다.

산출물은 적용할 규칙, 대상 회차, 작업 방식의 짧은 확인이다. 계획 설명으로 끝내지 말고 이미 요청된 작업을 이어 수행한다. 커밋·푸시·플랫폼 게시 권한은 스킬 호출만으로 추가되지 않는다.
