## 집필·검증 사용법 (확정)

2026-09-30 도입. 채팅에서 평소처럼 요청하면 다음 절차를 적용한다.

| 요청 예시 | 수행 절차 |
|---|---|
| `./task-start` 또는 `$task-start` | 최신 규칙·원고·작업 상태 확인 |
| `4화 써줘` 또는 `$novel-write 4화 써줘` | 준비 → 집필 → 검증 → 수정·재검증 |
| `1~3화 점검만 해줘` | 준비 → 검증 보고, 원고 수정 없음 |
| `2화 어색한 문장 고쳐줘` | 준비 → 해당 범위 퇴고 → 검증 |

스킬 원본: [작업 시작](skill/task-start/SKILL.md), [집필](skill/novel-write/SKILL.md), [검증](skill/novel-review/SKILL.md). AGENTS.md와 CLAUDE.md에서 같은 파일을 참조한다. 새 핵심 설정은 작가 승인 없이 확정하지 않는다.

2026-10-01 요청에 따라 실제 지침을 `skill/`에 모았다. [인덱스](skill/INDEX.md)에서 기존 설정집·구성·원고를 찾아 읽고 [공통 작업 지침](skill/working-rules.md)에 따라 시작·검증·마무리를 수행한다. `.agents/skills/`에는 자동 호출용 연결만 유지한다.

터미널에서는 저장소 루트의 PowerShell 7에서 실행한다.

```powershell
./task-start
./task-start -Mode write -Chapters 4
./task-start -Mode review -Chapters 1,2,3
./task-start -Mode review -Chapters 1,2,3 -AsJson
```

터미널 명령은 파일을 바꾸지 않고 규칙 경로·회차별 분량·“나는” 후보 위치를 출력한다. AI 집필을 별도로 실행하는 명령은 아니다. 다른 작품은 `-Work '작품폴더명'`으로 지정한다. 회차를 생략하면 현재 원고 전체를 확인한다. 검증 모드는 분량 미달·초과 또는 대상 파일 누락 시 종료 코드 1을 반환한다.

분량은 본문 공백 포함 5,500~6,000자. H1 제목·줄바꿈·강조/코드 표식은 제외하고 감정 결과의 내용은 포함한다. 일반 문단과 대사 중심의 현재 원고 형식용 검사이며, 임의의 Markdown을 렌더링하는 도구는 아니다. “나는” 후보는 동사 용례가 섞일 수 있어 문맥 확인이 필요하다. 문장과 설정 검증은 스킬 지침에 따라 원고를 직접 읽어 수행한다.

Codex는 저장소 `.agents/skills`에서 스킬을 발견하고 요청과 설명이 맞으면 사용할 수 있다. 목록에 나타나지 않으면 앱을 다시 시작하거나 AGENTS.md에 연결된 파일을 직접 읽도록 요청한다. [공식 스킬 문서](https://learn.chatgpt.com/docs/build-skills)
